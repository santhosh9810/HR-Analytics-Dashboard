# HR Analytics Dashboard

## Project Overview

This project analyzes employee data to identify attrition patterns and understand the key areas where employees are leaving the organization.

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Formulas
* Data Cleaning

## Key KPIs

* Total Employees: 1,470
* Employees Left: 237
* Attrition Rate: 16.12%
* Average Monthly Income: ₹6,502.93

## Analysis Performed

* Attrition by Age Group
* Attrition by Department
* Attrition by Job Role
* Overall Employee Attrition Rate

## Dashboard

The dashboard provides a visual overview of employee attrition and helps identify departments, job roles, and age groups with higher attrition.

## Key Insights

* Overall employee attrition rate is 16.12%.
* The 28–32 age group recorded the highest attrition.
* Research & Development recorded the highest number of employees leaving.
* Laboratory Technician recorded the highest attrition among the analyzed job roles.
